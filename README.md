# Yummy - Recipe Discovery Website 🍕

A modern, responsive web application for discovering and exploring recipes from around the world using TheMealDB API.

## 🌐 Live Demo
[**View Live Website**](https://dohahehe.github.io/Yummy/)

## 🌟 Features

### 🔍 Search & Discovery
- **Search by Name**: Find meals by their name.
- **Search by First Letter**: Browse meals alphabetically.
- **Category Filtering**: Explore meals by food categories.
- **Area/Cuisine Filtering**: Discover meals by geographical origin.
- **Ingredient-based Search**: Find meals containing specific ingredients.

### 📱 User Interface
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile.
- **Side Navigation**: Smooth sliding navigation panel.
- **Interactive Cards**: Hover effects and visual feedback.

### 🍽️ Recipe Details
- **Complete Meal Information**: Ingredients, measurements, and instructions.
- **Step-by-Step Instructions**: Formatted cooking directions.
- **Nutritional Info**: Area, category, and tags.
- **External Links**: Source and YouTube video links.

### 📞 Contact Form
- **Form Validation**: Real-time regex validation.
- **Multiple Fields**: Name, email, phone, age, password.
- **User Feedback**: Instant validation messages.
- **Secure Submission**: Password strength requirements.

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript (ES6+).
- **Styling**: Bootstrap 5, Custom CSS.
- **Icons**: Font Awesome, Bootstrap Icons.
- **API**: TheMealDB API.

## 🔗 API Credit & Data Source

### TheMealDB API
This project uses the **[TheMealDB API](https://www.themealdb.com/api.php)** as its primary data source for all recipe information.
